# Julie Guzal — portfolio

Nuxt 4 + Prismic portfolio for an art director. Statically generated (`nuxi generate`) and served by Apache on OVH shared hosting. English only (`lang="en"`).

## Commands

```bash
pnpm dev             # dev server (http://localhost:3000)
pnpm generate        # static build → .output/public (what production serves)
pnpm preview         # serve the generated build
pnpm lint            # eslint + stylelint (CI gate)
pnpm lint-fix
pnpm typecheck       # NOT a gate: ~100 pre-existing strict-mode errors, don't chase them
pnpm type-gen        # regenerate prismicio-types.d.ts from local models
npx prismic pull     # sync types/slices from Prismic (Type Builder is the source of truth)
```

## Workflow

- Git flow: branch `feature/*`, `fix/*`, `chore/*`, `perf/*` from `develop`, PR to `develop`, squash merge. Releases via `release/*` → `main`, tag triggers the production deploy.
- Conventional commits in English (`fix:`, `feat:`, `chore:`, `refactor:`, `perf:`, `style:`), used by git-cliff for `CHANGELOG.md`.
- One PR = one topic. CI (`.github/workflows/ci.yaml`) must be green: lint + generate.
- A PR is done when: lint passes, `pnpm generate` succeeds, the change is checked in a browser on `pnpm preview`, and the PR description carries the proof (Lighthouse numbers, screenshot/GIF, generated HTML excerpt, `curl -I` output…).
- Never commit secrets. They live in Bitwarden; GitHub/Netlify secrets are set by a human.

## Architecture

- `pages/[...uid].vue`: single catch-all page; fetches the Prismic document and renders `V<Type>Page` organisms (`components/organisms/V*Page.vue`).
- `slices/`: Prismic slices (`slices/index.ts` is generated by the Prismic CLI — don't edit or lint it).
- `components/{atoms,molecules,organisms}`: auto-imported. Components are `V`-prefixed.
- `composables/use-prismic-*.ts`: data fetching (`usePrismicFetchPage`, `usePrismicFetchDocuments`), SEO/head.
- `transitions/card-transition.ts` + `middleware/page-transition.global.ts`: GSAP page transitions. `plugins/gsap.client.ts`, `plugins/lenis.client.ts`: smooth scroll.
- Deploy: `.github/workflows/build-prod.yaml` (tag or `repository_dispatch`) generates then SFTPs to OVH. Prismic publish webhook → `netlify/functions/run-gh-dispatches.mts` → GitHub `repository_dispatch`.

## Gotchas

- **Static hosting**: `nitro.routeRules` `headers`/`isr`/`redirect` are NOT applied in production (no Nitro server). HTTP headers, cache and real 301s belong in `public/.htaccess`.
- **@prismicio/vue v6**: no `wrapper` prop on `PrismicRichText` / `SliceZone` (they render fragments — wrap them yourself); rich-text component overrides receive `node` and get the text through the default slot (`node.text` is undefined); `filter` comes from `@prismicio/client`, not `usePrismic()`.
- **@nuxt/image v2**: its internal props/utils are no longer exported; `VImg`, `VPicture`, `VPrismicImage` use the copy in `utils/image/nuxt-image-props.ts`.
- **Prismic models**: change them in the Type Builder / via the `prismic` CLI, never by hand in `customtypes/**` or `slices/*/model.json`. `prismicio-types.d.ts` is generated.
- **pnpm 11** (`pnpm-workspace.yaml`): `minimumReleaseAge` rejects packages published < 24 h ago — pick an older version, don't bypass it. `allowBuilds` must list any dependency needing a build script. TypeScript is pinned to 5.9 via `overrides` until typescript-eslint supports TS 7.
- **Styles**: SCSS modules (`<style lang="scss" module>`, `$style.x`), BEM-like class names, 4-space indent. `assets/scss/_resources.scss` is injected in every component (variables/mixins/functions only — no CSS output there). Use `@if/@else`, not the deprecated Sass `if()` function.
- Splash screen, page transitions and custom cursor are desktop-oriented; always check `prefers-reduced-motion` and keyboard access when touching them (RGAA is required).
